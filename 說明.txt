寶石匠人｜手機網頁版

這個資料夾就是整個遊戲（index.html 為入口）。放到網站空間後，用手機瀏覽器開網址就能玩。
直接在電腦上雙擊 index.html 不能玩，一定要放上網站空間或用本機伺服器開啟。

上傳方式（擇一）：
1. itch.io（推薦，免費）：新增專案 → Kind of project 選「HTML」→ 上傳本資料夾壓縮成的 zip
   → 勾選「This file will be played in the browser」與「Mobile friendly」→ 存檔後即得網址。
2. Netlify Drop：登入後把整個資料夾拖進 app.netlify.com/drop。
3. GitHub Pages：把資料夾內所有檔案放進 repository，開啟 Pages。

電腦測試：在此資料夾執行 python3 -m http.server 8000，再開 http://localhost:8000

玩法：
- 首頁「接受委託」：第 1～30 關依序解鎖（螢石 → 蛋白石 → 藍寶石 → 祖母綠 → 紅寶石 → 鑽石）。
- 第 1～5 關是教學關：點範本的面可以取用角度（連同對稱），「距中心」也會並列範本數值，對準變綠。第 1 關有逐步引導。
- 點寶石選擇切面、調深度、按「下刀！」；拖曳轉動視角。上方的「預估鑑定」每刀即時更新。
- 按「範本」會跳出大視窗顯示客人要的成品（蓋住畫面，關閉後才能繼續刻）。
- 第 5 關過關後遊戲正式開始：從第 6 關起範本只能看、可旋轉，不能取用，也不顯示範本數值。
- 「自由切削」有十種原石，新增紫水晶（天然水晶柱原石）、貓眼石（拋光後浮出貓眼亮線）、黃鑽（八面體原石）、亞歷山大石（按「燈光」在日光綠／燭光紅紫之間變色）。
- 鑑定後可「存入收藏櫃」，在首頁的「收藏櫃」觀看。
- 瀏覽器會在第一次觸碰畫面後才開始播放音樂。
